# Museu do Rádio

Primeira versão do Museu do Rádio, uma experiência digital e interativa desenvolvida com HTML, CSS e JavaScript puro.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Sem framework e sem etapa de build

## Rodando localmente

Abra o arquivo `index.html` diretamente no navegador ou use um servidor HTTP local.

Exemplo com Python:

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Deploy no Vercel

1. Importe este repositório no Vercel.
2. Selecione `Other` como framework, caso solicitado.
3. Não é necessário configurar Build Command.
4. O diretório de saída é a raiz do projeto.
5. Faça o deploy.
